פרויקט Android — ניהול המסעדה שלי
=================================

מה כלול
-------
- אפליקציית Android שמציגה את ממשק ניהול המסעדה בתוך WebView.
- קוד HTML/CSS/JavaScript נמצא ב:
  app/src/main/assets/index.html
- שכירות חודשית ₪13,337 ושכירות מחסן ₪1,770 מוגדרות כברירת מחדל.
- תמלוגים 6% וטאביט 1% מהמחזור מוגדרים כברירת מחדל.
- שמירת נתונים מקומית ב-WebView; אין סנכרון לענן.
- ייצוא גיבוי ודוח CSV נשמרים בתיקיית Downloads של המכשיר.
- ייבוא גיבוי מאפשר לבחור קובץ JSON דרך בורר הקבצים של Android.
- חדש: ייבוא הוצאות מ-Excel, CSV/TSV/TXT, PDF, תמונות חשבוניות ו-ZIP של ייצוא WhatsApp.
- המערכת מנסה לזהות תאריך, ספק וסכום ומציגה טיוטה לעריכה ואישור לפני שמירת ההוצאות.
- קריאת PDF/Excel/OCR משתמשת בספריות שמוטענות מהאינטרנט; נדרש חיבור לאינטרנט. הזיהוי אינו מובטח ויש לבדוק כל שורה לפני שמירה.

איך להפיק APK
--------------
1. התקן Android Studio במחשב (לא ניתן לבנות APK מתוך הטלפון בלבד בעזרת הקבצים האלה).
2. חלץ את קובץ ZIP של הפרויקט לתיקייה.
3. פתח Android Studio ובחר Open, ואז בחר את תיקיית RestaurantManagerAndroid.
4. המתן ל-Gradle Sync. אם תתבקש, התקן Android SDK Platform 35 ו-Build Tools.
5. בתפריט Build בחר Build Bundle(s) / APK(s) > Build APK(s).
6. לאחר סיום הבנייה, לחץ Locate בהודעה שמופיעה. בדרך כלל הקובץ יהיה:
   app/build/outputs/apk/debug/app-debug.apk
7. העבר את ה-APK לטלפון, פתח אותו ואשר התקנה ממקור זה אם Android מבקש זאת.

איך לערוך
----------
- עריכת ממשק/עיצוב/לוגיקה של האפליקציה: פתח app/src/main/assets/index.html.
- עריכת מסך Android או התנהגות WebView: פתח app/src/main/java/com/zalmans/restaurantmanager/MainActivity.java.
- שם האפליקציה: app/src/main/AndroidManifest.xml.
- לאחר שינוי קוד, בנה APK חדש באותו תהליך.

חשוב
----
- הפרויקט הוא קוד מקור ולא APK מוכן. נדרש Android Studio עם Android SDK כדי להפיק את קובץ ההתקנה.
- מומלץ לייצא גיבוי באופן קבוע. הסרת האפליקציה או ניקוי נתוני האפליקציה עלולים למחוק נתונים מקומיים.
- בדוק את האפליקציה ואת תהליך הגיבוי במכשיר לפני שימוש עסקי שוטף.

אפשרות לבנייה בענן (ללא התקנת Android Studio)
------------------------------------------------
בתיקיית .github/workflows נמצא תהליך אוטומטי לבניית APK ב-GitHub Actions.
כדי להשתמש בו יש להעלות את כל הפרויקט למאגר GitHub, להיכנס ללשונית Actions,
להפעיל את הפעולה Build Android APK, ואז להוריד את הקובץ מה-Artifacts של הריצה.
השלב הזה דורש חשבון GitHub והעלאת קובצי הפרויקט למאגר.
